# 智光商工 資料處理科 一年仁班 段考學習檢討與診斷系統

專為 **新北市私立智光高級商工職業學校 資料處理科 一年仁班 26 號 高于翔 同學** 量身打造的高質感段考學習成效檢討與自主學習輔導系統。

---

## 🌟 核心特色與功能模組

1. **科技感暗色系與玻璃擬態設計（Cyber Dark & Glassmorphism）**
   - 契合資料處理科（資處科）之資訊與程式設計專業形象。
   - 具備霓虹光暈、微互動動畫與現代字體。

2. **學生個人學籍名片與段考切換**
   - 預設顯示：一年仁班 26 號 高于翔（支援點擊右上角隨時編輯學生姓名、學號、座號與座右銘）。
   - 支援切換「高一上 第一次段考」、「高一上 第二次段考」及「高一上 期末考」。
   - 下次段考衝刺即時倒數計時器。

3. **四大關鍵績效指標卡（KPI Metrics）**
   - **段考總分**與滿分達成率（632分 / 700分，達成率 90.3%）。
   - **總平均分數**與班級常模落點百分比（總平均 90.3分，穩居頂尖榜首群 前 3%）。
   - **全班預估名次**（全班第 3 名 / 31 人常模）。
   - **及格科目數**（7/7 全數及格）。

4. **七大學科能力雷達分析圖（Interactive Radar Chart）**
   - 涵蓋高一七大核心考科：
     - **資訊科技**（93分 - 全科之冠王牌科目）
     - **物理**（92分 - 理科優勢雙雄）
     - **數學**（92分 - 數理邏輯雙雄）
     - **國文**（91分 - 語文素養優異）
     - **會計**（90分 - 商管核心專業）
     - **商業概論**（90分 - 商管核心專業）
     - **英文**（84分 - 核心培優關鍵科）
   - 原生 Canvas 高解析度繪製：我的成績（發光藍）vs 班級平均（對比灰）vs 60分及格虛線（警戒紅）。

5. **AI 智能學情診斷報告**
   - 自動辨識王牌科目與不及格弱科。
   - 針對資處科專業科目提供具體學習建議（如會計借貸法則、計概進位換算與通訊協定、程式迴圈運算思維）。

6. **各科動態成績卡片與心得錄入**
   - 點擊「編輯成績」可修改分數、目標分、失分檢討與改善對策，所有圖表即時連動重算！

7. **三大核心分頁系統**
   - **段考錯題收錄本**：依科目與失分原因（觀念不熟、粗心計算、時間不足、語法誤判）篩選，支援新增錯題、失分標記與解題解析。
   - **資處科專業考點衝刺秘笈**：整理計概進位/五大單元、程式設計資料型態與迴圈、會計學借貸口訣（資產費損在左借、負債權益收益在右貸）、商概 4P/SWOT。
   - **段考自我省思四部曲**：溫習時間、手機管制、上課專注度評估，以及亮點與改善行動承諾，即時自動存檔。

8. **正式紙本檢討表列印 / 匯出 PDF（Print Ready）**
   - 點擊「列印檢討單」或按 `Ctrl+P`，自動轉化為符合高職標準格式的正式 A4 紙本表格。
   - 包含完整成績對比、錯題摘要、自我省思，以及**「學生簽章、家長簽名、導師評語簽核、科主任核閱」**欄位，可直接印出繳交！

## 🚀 如何開啟與使用

- 直接在 Windows 檔案總管中，**雙擊滑鼠左鍵開啟 `index.html`**，即可使用任何主流瀏覽器（Chrome、Edge、Firefox 等）瀏覽與操作。
- 本系統具備瀏覽器本地儲存（`localStorage`），所有輸入的分數與筆記在重新整理後皆不會遺失。
- 點擊底部「重設回預設範例」可隨時還原完整的高一仁班範例資料。
