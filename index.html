物理必考重點（力學與能量）

  • 等加速度運動三大公式： ① v = v₀ + at ② Δx = v₀t + ½at² ③ v² = v₀² + 2aΔx。
  • 牛頓運動定律： 第一定律慣性；第二定律 F=ma（合力與加速度同向）；第三定律作用反作用力（同值反向不同體）。
  • 動能與力學能守恆： 動能 Ek = ½mv²；重力位能 Ep = mgh；無外力阻力下 Ek + Ep = 定值。
  • 功率與功： 功 W = F·s·cosθ；功率 P = W/t = F·v。

資訊科技必考重點

  • 進位轉換口訣： 二進制(BIN)、八進制(OCT)、十進制(DEC)、十六進制(HEX)。由整數除基數取餘數倒記，小數乘基數取整順記。
  • 容量單位順序： Byte < KB (210) < MB (220) < GB (230) < TB (240) < PB。
  • 計算機五大單元： 輸入(IU)、輸出(OU)、算術邏輯(ALU)、控制(CU)、記憶單元(MU)。ALU+CU = CPU。
  • 網路通訊協定： HTTP (80埠), HTTPS (443埠 SSL/TLS安全加密), FTP (20/21埠), DNS (Domain轉IP)。

會計基礎借貸口訣

  • 基本恆等式： 資產 (Assets) = 負債 (Liabilities) + 業主權益 (Equity)。
  • 借貸法則口訣： 借方(Dr.)增加：資產、費損 (資產花費往左借)； 貸方(Cr.)增加：負債、業主權益、收益 (貸方生財向右放)。
  • 常見科目： 現金、應收帳款、存貨 (資產類)；應付帳款、短期借款 (負債類)；銷貨收入 (收益類)；薪資支出、水電費 (費損類)。
  • 折扣條件處理： 2/10, n/30 代表 10 天內付款享有 2% 折扣，滿期 30 天付清。總額法收款認列「銷貨折讓」。

商業概論重要常考觀念

  • 行銷 4P 理論： 產品 (Product)、價格 (Price)、通路 (Place)、促銷 (Promotion)。
  • SWOT 分析矩陣： 優勢 (Strengths)、劣勢 (Weaknesses)、機會 (Opportunities)、威脅 (Threats)。
  • 企業經營機能： 生產、行銷、人力資源、研發、財務 (生銷人發財)。
  • 現代新零售模式： O2O (線上線下整合)、無人商店、電子商務 B2B / B2C / C2C。

數學必考核心公式

  • 直線方程式與斜率： m = (y₂ - y₁) / (x₂ - x₁)；兩垂直直線斜率相乘 m₁·m₂ = -1；平行直線 m₁ = m₂。
  • 二次函數頂點式： y = a(x - h)² + k，頂點 (h, k)；判別式 D = b² - 4ac 判斷與 x 軸交點數。
  • 乘法公式與因式分解： (a+b)³ = a³ + 3a²b + 3ab² + b³；a³ - b³ = (a - b)(a² + ab + b²)。

英文閱讀與克漏字奪分關鍵

  • 高頻轉折詞： However / Nevertheless (然而轉折), Furthermore / Moreover (此外遞進), Therefore / Consequently (因此因果)。
  • 常見時態陷阱： 過去進行式 (was/were V-ing) 表當時持續；現在完成式 (has/have p.p.) 表經驗或自過去持續至今。
  • 速讀策略： 閱測先讀題目關鍵字 (Keywords)，回文鎖定段落首尾句精準定位定位點。

國文語文常識與成語精要

  • 六書造字法則： 象形、指事 (獨體為文，造字之法)；會意、形聲 (合體為字，造字之法)；轉注、假借 (用字之法)。
  • 常考成語古今涵義： 「差強人意」指尚能令人滿意，非極差或極佳；「明日黃花」指過時事物，非明日之花。
  • 題辭判讀： 嫁女用「桃灼呈祥」；弄璋之喜 (生男)；弄瓦之喜 (生女)；長壽用「福壽雙全」。
